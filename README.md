# 🛒 Mini E-commerce - Учебный интернет-магазин

Полноценное веб-приложение интернет-магазина с frontend на React, backend на Node.js/Express и базой данных SQLite.

## 📋 Описание

Mini E-commerce — это учебный проект интернет-магазина с полным функционалом для демонстрации современных веб-технологий. Приложение включает каталог товаров, поиск, фильтрацию, корзину покупок и работу с backend API.

**⚠️ Важно:** Это учебный проект. Реальная оплата не реализована, банковские данные не запрашиваются.

## 🚀 Установка и запуск

### Требования
- Node.js версии 16 или выше
- npm или yarn

### 1. Клонирование репозитория
```bash
git clone https://github.com/zainabmambetkulovva/-9.git
cd проект9
```

### 2. Установка Backend

```bash
# Перейти в папку backend
cd backend

# Установить зависимости
npm install

# Сгенерировать Prisma Client
npm run prisma:generate

# Создать базу данных и применить миграции
npx prisma migrate dev --name init

# Заполнить базу данных начальными данными
npm run prisma:seed

# Запустить сервер
npm start
```

Backend запустится на `http://localhost:5000`

### 3. Установка Frontend

Откройте новый терминал:

```bash
# Перейти в папку frontend
cd frontend

# Установить зависимости
npm install

# Запустить приложение
npm start
```

Frontend запустится на `http://localhost:3000`

### 4. Открыть приложение

Откройте браузер и перейдите по адресу: **http://localhost:3000**

## 📡 API Endpoints

### Товары
- `GET /api/products` - Получить все товары (с поддержкой фильтрации, поиска, сортировки)
- `GET /api/products/:id` - Получить товар по ID
- `POST /api/products` - Создать новый товар
- `PUT /api/products/:id` - Обновить товар
- `DELETE /api/products/:id` - Удалить товар
- `GET /api/categories` - Получить все категории

### Корзина
- `GET /api/cart` - Получить содержимое корзины
- `POST /api/cart` - Добавить товар в корзину
- `PUT /api/cart/:id` - Обновить количество товара
- `DELETE /api/cart/:id` - Удалить товар из корзины
- `DELETE /api/cart` - Очистить корзину

### Health Check
- `GET /api/health` - Проверка работоспособности сервера

## 🧪 Тестирование

### Ручное тестирование функциональности

#### ✅ Каталог и отображение
1. Откройте приложение
2. Убедитесь, что отображается 15 товаров
3. Проверьте, что каждая карточка содержит: изображение, название, цену, категорию, количество на складе

#### ✅ Поиск
1. Введите в поле поиска "наушники"
2. Должен отобразиться товар "Беспроводные наушники Sony"
3. Очистите поиск - все товары вернутся

#### ✅ Фильтрация по категории
1. Выберите категорию "Электроника"
2. Должны отобразиться только товары этой категории
3. Верните "Все категории" - товары вернутся

#### ✅ Сортировка
1. Выберите "Цена: по возрастанию"
2. Товары должны отсортироваться от дешевых к дорогим
3. Выберите "Цена: по убыванию" - порядок изменится

#### ✅ Добавление в корзину
1. Нажмите кнопку "В корзину" на любом товаре
2. Счетчик на кнопке корзины должен увеличиться
3. Откройте корзину - товар должен быть там

#### ✅ Управление корзиной
1. Откройте корзину
2. Измените количество товара кнопками +/-
3. Общая сумма должна пересчитаться автоматически
4. Удалите товар кнопкой 🗑️
5. Добавьте несколько товаров и очистите корзину

#### ✅ Детальная страница товара
1. Нажмите на карточку товара
2. Откроется детальная страница с полным описанием
3. Выберите количество и добавьте в корзину
4. Вернитесь назад кнопкой "← Назад к каталогу"

#### ✅ Адаптивность
1. Измените размер окна браузера
2. Интерфейс должен адаптироваться под разные размеры экрана

## 🐛 Решение проблем

### Ошибка подключения к backend
- Убедитесь, что backend запущен на порту 5000
- Проверьте файл frontend/package.json - должен быть proxy: "http://localhost:5000"

### База данных не создается
```bash
cd backend
rm -rf prisma/dev.db
npx prisma migrate dev --name init
npm run prisma:seed
```

### Порт уже занят
Измените порт в файле backend/.env:
```
PORT=5001
```
