# 📦 Руководство по установке и запуску Mini E-commerce

## Быстрый старт

### Шаг 1: Установка зависимостей Backend

```bash
# Откройте терминал в корневой папке проекта
cd backend

# Установите зависимости
npm install

# Сгенерируйте Prisma Client
npx prisma generate

# Создайте базу данных и примените миграции
npx prisma migrate dev --name init

# Заполните базу данных тестовыми товарами
node prisma/seed.js
```

### Шаг 2: Запуск Backend сервера

```bash
# В папке backend
npm start
```

Вы должны увидеть:
```
✅ Сервер запущен на порту 5000
🌐 API доступен по адресу: http://localhost:5000/api
```

**Оставьте этот терминал открытым!**

### Шаг 3: Установка зависимостей Frontend

Откройте **новый терминал**:

```bash
# Перейдите в папку frontend
cd frontend

# Установите зависимости
npm install
```

### Шаг 4: Запуск Frontend приложения

```bash
# В папке frontend
npm start
```

Браузер автоматически откроется на `http://localhost:3000`

## Проверка работоспособности

### 1. Проверка Backend API

Откройте браузер и перейдите по адресу: http://localhost:5000/api/health

Вы должны увидеть:
```json
{"status":"ok","message":"Сервер работает"}
```

Проверьте товары: http://localhost:5000/api/products

Должен отобразиться JSON с 15 товарами.

### 2. Проверка Frontend

Откройте http://localhost:3000

Вы должны увидеть:
- ✅ Каталог с 15 товарами
- ✅ Поле поиска
- ✅ Фильтры категорий и сортировки
- ✅ Кнопку корзины в хедере

## Тестирование функциональности

### Поиск
1. Введите "наушники" в поле поиска
2. Должен остаться только один товар

### Фильтрация
1. Выберите категорию "Электроника"
2. Отобразятся только товары этой категории

### Сортировка
1. Выберите "Цена: по возрастанию"
2. Товары отсортируются от дешевых к дорогим

### Корзина
1. Нажмите "В корзину" на любом товаре
2. Кликните на кнопку корзины в хедере
3. Проверьте, что товар добавился
4. Измените количество кнопками +/-
5. Удалите товар кнопкой 🗑️

### Детальная страница
1. Кликните на карточку товара
2. Откроется страница с подробной информацией
3. Выберите количество и добавьте в корзину

## Возможные проблемы и решения

### "npm" не распознается

**Решение:** Установите Node.js с официального сайта https://nodejs.org/

### Порт 5000 уже занят

**Решение:** Измените порт в файле `backend/.env`:
```
PORT=5001
```

Также обновите proxy в `frontend/package.json`:
```json
"proxy": "http://localhost:5001"
```

### Ошибка Prisma "Database not found"

**Решение:** Запустите миграции заново:
```bash
cd backend
rm -rf prisma/dev.db
npx prisma migrate dev --name init
node prisma/seed.js
```

### Frontend не подключается к Backend

**Проверьте:**
1. Backend запущен и работает (http://localhost:5000/api/health)
2. В консоли браузера нет CORS ошибок
3. Proxy настроен в frontend/package.json

### База данных пустая

**Решение:** Заполните базу данных:
```bash
cd backend
node prisma/seed.js
```

```bash
npm start
```
