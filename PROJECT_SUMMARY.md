8. `POST /api/cart` - добавить в корзину
9. `PUT /api/cart/:id` - обновить количество
10. `DELETE /api/cart/:id` - удалить из корзины
11. `DELETE /api/cart` - очистить корзину

## ⚠️ Требуется выполнить вручную

Из-за ограничений разрешений, следующие команды нужно выполнить вручную:

### 1. Установка зависимостей Backend
```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev --name init
node prisma/seed.js
npm start
```

### 2. Установка зависимостей Frontend
```bash
cd frontend
npm install
npm start
```

### 3. Проверка работоспособности
После запуска обоих серверов:
1. Откройте http://localhost:3000
2. Проверьте каталог товаров
3. Попробуйте поиск и фильтрацию
4. Добавьте товары в корзину
5. Откройте детальную страницу товара
